# SafeMobile Privacy Policy

SafeMobile is 100% offline and collects zero telemetry. All scans happen locally on-device.

**Clarification:** "100% offline" describes core scanning, which can work without network access. It does not mean that *all app functions* are network-free. Optional signed threat-intelligence/model downloads use GitHub, and an explicit Pro checkout uses Google Play Billing. SafeMobile does not send APKs, file hashes, scan results or scan history to a developer-operated server.

Sensitive records and scan history stay in local app-private storage. Uninstalling or clearing app data removes local records and can permanently remove a device-bound Pro pass. No analytics SDK or developer crash telemetry is used.

The Phase F cloud benchmark runs solely in a disposable GitHub Actions environment using separately obtained research APKs; no samples are bundled into the user app.

For detailed permissions, network endpoints, backup and purchase policy see [the in-app privacy notice](../app/src/main/assets/privacy-policy.md).
