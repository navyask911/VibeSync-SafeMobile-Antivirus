# Phase F: verified research ML candidate

- Android app contains the **exact 215-feature schema** from the separate Drebin ML training repository.
- On every clean build, the app stages the release **v1.0.1-model** TensorFlow Lite binary (18,584 bytes) from the publisher into the generated APK assets folder. A SHA-256 pin of 8b66adaf01a939c26d5a756e66f53fe0d6e85e1a06ec97166579138c6ce47061 and schema pin ffb386be14adf8c0af1bb96032e5485fcc8fd5b401a24488c5896e2d5ea425ac must both pass. Build fails closed if the artifact is missing or mismatched. No model download occurs on a user's device.
- The **old 32-input 912-byte dummy model is no longer packaged**. The model metadata reflects exactly 215 features and a trained research candidate: dummy_untrained=false, trained=true. The 97.450034% reported TFLite holdout accuracy is a historical **Drebin research result**, not a claim of SafeMobile TPR.
- Separate research-only scoring via MachineLearningScanner.scanResearchCandidate() feeds the provenance-gated benchmark. No research ML score changes a production threat verdict.
- **validated=false, production_ready=false** deliberately remain until an independent APK/feature-extractor performance evaluation, threshold calibration, and sign-off. The normal MachineLearningScanner.scan() requires those flags and remains unavailable for production classification.
- Ownership/provenance: [v1.0.1-model release](https://github.com/navyask911/safemobile-Antivirus-Trained-ML-Data-of-Android-malware/releases/tag/v1.0.1-model).
