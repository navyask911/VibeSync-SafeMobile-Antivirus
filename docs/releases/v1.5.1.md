# SafeMobile v1.5.1

- **Version name:** 1.5.1
- **Version code:** 20261124
- **Package:** `com.vibesync.antivirus`

## Release highlights

- Adds Paparazzi visual-regression coverage for the Security Dashboard, scan-results screen, and Settings panel in Light and Midnight themes.
- Commits six reviewed UI snapshot baselines and documents the snapshot verification/recording workflow.
- Preserves the existing scan-result remediation, trust, and quarantine callbacks.
- Retains the existing offline/feed build variants, Play Billing subscription integration, and AdMob consent/gating behavior.

## Validation

The Android CI run for the merged v1.5.1 change passed all five jobs, including unit tests and Paparazzi snapshot verification, lint, release-variant build/signature checks, and instrumented tests on API 26, 33, 34, and 36.

## Release artifacts

The release workflow builds and verifies the signed offline APK and Google Play AAB. The AAB is intended for manual upload through the Google Play Console; this workflow does not publish directly to the Play Store.
